# 下载并静默安装 Darra EtherCAT 运行时

这个技能只做一件事：把 Darra EtherCAT 运行时下载下来，校验，然后按官方安装器的静默参数装上或者卸掉。

参数和退出码都以这份文件为准，不要自己加，也不要猜。

先记住一句话：这个包会安装实时驱动，还可能预留实时核。动手之前必须跟用户说清楚，拿到确认再执行。

## 1. 先说清楚，拿到确认

动手前对用户说明：

- 要下载并安装 Darra EtherCAT 运行时（官方安装包，一次常规软件安装）。
- 会替换机器上的实时驱动；如果带 `--rt-masters`，还会预留对应的实时核。
- 装完可能需要重启才生效。

用户没有确认就不要执行。不许「先装上再说」。

## 2. 核对前提

- 系统：公开包只有 Windows x64。Windows 版本、运行库等要求以下载页为准：https://ethercat.darra.xyz/doc/downloads
- 权限：需要管理员权限。没有管理员权限会失败（退出码 1），先跟用户确认。
- 机器：不建议装在日常开发机上，尤其是用 USB 网卡的笔记本。用户的生产机、现场机更合适。
- 平台：Linux 还没有公开发布，不要写 Linux 安装命令。

## 3. 下载并校验

固定直链，不带版本号：

```
https://download.darra.xyz/ethercat/client/Darra-EtherCAT-Setup.exe
```

校验文件是同一地址加 `.sha256`：

```
https://download.darra.xyz/ethercat/client/Darra-EtherCAT-Setup.exe.sha256
```

下载后算 SHA256，和校验文件里的值比对。不一致就停手，把两个值告诉用户，不要「先装再看看」。

也不要去猜 `Darra-EtherCAT-Setup-2.13.15.exe` 这种带版本号的文件名，猜出来的地址拿不到包。

## 4. 安装

装没装过旧版都用同一条命令，不用先看有没有旧版，也不用卸掉旧版：

```
Darra-EtherCAT-Setup.exe --silent --install
```

安装器会按机器上的驱动状态自己处理已装版本：先停旧驱动，再删旧驱动与旧程序文件，然后装本次版本。所以升级就是再跑一次安装包，不需要把旧版卸掉再重装那一套。

卸载是另一个独立动作，只在用户明确要求卸载时才执行：

```
Darra-EtherCAT-Setup.exe --silent --uninstall
```

可选参数，只在需要时加：

- `--path DIR`：指定安装目录。
- `--no-rt-optimize`：跳过实时优化。
- `--rt-masters 1..4`：RT 主站数，也就是预留的实时核数，装完记在机器上。

`--rt-masters` 缺值、不是整数、或者超出 1 到 4，安装器会直接失败。不要把它改成 1 再试，先跟用户确认要几个。

没有 `--repair`，加了会被拒；也没有对外的 `--resume`，那是安装器重启后自己收尾用的。别编参数。

## 5. 看退出码，决定下一步

| 退出码 | 含义 | 下一步 |
|---|---|---|
| 0 | 成功 | 继续后面的步骤 |
| 1 | 失败（未分类异常，或没有管理员权限） | 确认管理员权限和安装包完整性，重试一次；还失败就如实告诉用户 |
| 1602 | 用户取消，动作没有执行 | 问用户还要不要装，不要自动重装 |
| 1603 | 执行中出错（含空间不足、临时目录写不进去） | 查磁盘空间和权限，处理后再跑 |
| 1604 | 卸载没做全，机器上还剩文件 | 如实告诉用户还剩什么，按提示处理，或者联系 support@darra.xyz |
| 1618 | 另一个安装 / 卸载事务正在跑 | 等它结束后重试，不要同时开几个安装器 |
| 1622 | 日志写不进去，动作已停手 | 先解决磁盘空间、目录写权限，再重跑 |
| 1639 | 命令行参数对这个动作不可用 | 按上面的命令重写，不要自己加参数 |
| 3010 | 操作成功，重启后生效 | 成功码，不是失败。两档都算成功：① 本趟已装完，重启后生效；② 驱动本趟停不下来，安装器已安排好开机换入，重启后自动收尾，不必再跑安装包。告诉用户「已安装成功，需要重启才生效」，由用户决定什么时候重启 |

3010 单独说一句：不要自动重启机器，只有用户明确同意后才能重启。不管是哪一档，都不要因为「还没生效」就反复重装。

## 6. 装完怎么验证

- 重启后打开 Darra EtherCAT Master 配置工具，能正常扫描从站，说明运行时已经就位。步骤见 https://ethercat.darra.xyz/doc/quick-start/preparation
- 用 SDK 的话，按 SDK 文档读主站状态、进 OP（例如 C# 的 `master.SetState(EcState.OP, out err)` 返回成功）。以 SDK 文档为准：https://ethercat.darra.xyz/doc/sdk/csharp/master/diagnostics
- 验证不通过先看退出码和日志，不要靠反复重装解决。

## 7. 不要做的事

- 不要猜带版本号的安装包文件名，只用固定直链。
- 不要把升级拆成卸载、重启、安装三步：升级直接覆盖安装，安装器会接管已装版本。
- 不要自动重启用户的机器。
- 不要在日常开发机上装。
- 不要编造参数（`--repair` 不存在，`--resume` 不是对外参数）。
- 不要在校验和不符时装。
- 不要在没告诉用户的情况下装。
