# Darra EtherCAT Master 图形界面

这份 skill 只讲界面怎么点。要写主站程序（周期回调、业务逻辑、伺服使能），用 `darra-ethercat` 技能，API 以 https://ethercat.darra.xyz/ai-prompts.txt 为准。

下面按中文界面写。换语言后按钮文字会变，认位置和控件类型；界面里没有的能力见最后一节，不要硬找。

## 最短路径

1. `切换` → 选主网口 → `确认`，等主站建好（停在 PreOp）。
2. 需要时用 `导入` 加载 ESI / ENI / DENI。
3. 在左侧从站树选从站，配 PDO 映射、启动参数、DC。
4. `状态机` → `OP`。
5. 看 `PDO` 页、`信息` 页、`诊断` 页。
6. 用 `导出` 存 DENI、导出程序或调试信息。

## 1. 打开与初始状态

启动 Darra EtherCAT Master 工具（安装入口以实际安装为准）。程序以管理员权限运行，启动时会弹 UAC，需要允许。左上标题显示 `DarraTech EtherCAT Master Tools <版本>`。

界面分六块：

| 区域 | 内容 | 用途 |
|---|---|---|
| 顶部导航条 | `状态机`、`导入`、`导出`、`更多工具`、`自检`、`帮助`、`注册`、`RT` 徽标、`语言`、`最小化`、`关闭` | 全局操作 |
| 左栏上 | `步骤1: 选择网络适配器` + `切换`；`步骤2: 选择模块` + `扫描` | 选网卡、重建/重扫 |
| 左栏下 | 从站树：`名称`、`状态`、`ESI` | 选主站节点或从站 |
| 中间 | 页签区（见下表） | 当前选中对象的详细页 |
| 右栏 | `主站配置`（高级开关）、`从站配置`（`开始自动配置`、`写入PDO分配`、`写入PDO配置`、`组:`） | 主站/从站参数 |
| 底部 | `Logs` 日志面板 + 状态栏 | 日志与实时指标 |

中间页签及用途：

| 页签 | 用途 |
|---|---|
| `欢迎` | 初始页；`快速开始` 四步、`下载类库`、`用户手册`、`技术支持`、`API参考手册` |
| `信息` | 分组属性表，运行时表头为 `Category`、`Parameter`、`Value`、`Unit`、`Description`（首列分组） |
| `诊断` | 主站诊断、实时性能、DC 同步、拓扑图 |
| `DC` | 主站节点的 PDO 交换周期；从站节点的 DC 模式、周期、SYNC0/SYNC1、同步窗口 |
| `启动` | 启动参数（Startup SDO）计划 |
| `FMMU/SM` | PDO 映射选择（`选择输入` / `选择输出`） |
| `MDP` | 模块化从站：`当前模块` / `可选模块` |
| `CoE` / `SoE` / `EoE` / `FoE` / `AoE` / `VoE` / `FSoE` | 对应邮箱协议的页 |
| `CiA 402` / `CiA 401` | 驱动器/IO 档案页（402 只监视，见第 9 节） |
| `PDO` | 运行中的过程数据值 |
| `主站配置` | 状态切换超时、看门狗超时、VLAN |
| 组页 | 从站组分配与组配置；页面标题未在仓内固定，以实际界面为准 |

初始状态：只显示 `欢迎` 页；从站树是空的；状态栏最左工作状态为 `未连接`，其后各项为 `--`；`RT` 徽标显示 `RT On` / `RT Ready` / `RT Degraded` / `RT Error` / `RT Off` 之一。右栏 `主站配置` 容器始终在；`从站配置` 要等选中从站后才出现。

`更多工具` 下另有 `从站配置验证器`（按当前配置做校验）、`直接寄存器访问`（ESC 寄存器读写调试）、`邮箱统计`（按从站/协议统计发送、接收、超时、邮箱错、协议错、最后错误码、平均延迟）、`检查 ESI 冲突`（ESI 资产治理，按需检测）。`自检` 执行只读体检。

右栏 `主站配置` 面板里的开关和数值项：`PDO帧优化`、`帧高优先级`、`UDP模式`、`启用诊断`、`自适应超时`、`互斥锁保护`、`邮箱网关`、`DC漂移补偿` 是开关，`帧重复`、`丢帧阈值` 是数值框。这些是高级选项，每项都有悬停说明；没有特殊场景就保持默认。选中 `Master` 节点时，中间的 `主站配置` 页可改状态切换超时、PDI/过程数据看门狗超时和 VLAN。

**怎么确认这一步成功了**：能看到 `DarraTech EtherCAT Master Tools <版本>`、`欢迎` 页的 `快速开始`、空从站树、工作状态 `未连接` 和其后全 `--` 的状态栏。

## 2. 选网卡 / 扫描

### 列出网卡

点左栏 `切换`，打开 `加载网卡` 对话框。对话框打开后自动枚举网卡并快扫，状态行依次显示 `正在加载网络适配器...`、`发现 N 个已绑定网口`、`正在快扫所有网口…`。

主网口下拉的列：

| 列 | 说明 |
|---|---|
| `名称` | Windows 连接名 |
| `网卡型号` | 适配器型号/描述 |
| `GUID` | 适配器 GUID |
| `从站数量` | 该口快扫结果（只有主网口下拉有这一列） |

`从站数量` 列的含义必须分清：

| 显示 | 含义 |
|---|---|
| `0` | 实测空口：扫过了，确实 0 个从站 |
| `—` | 没量到：本轮没有该口的结论，不等于 0 个从站 |
| `占用中` | 该口正被当前主站占用；有已知站数时显示 `N(在用)` |
| `未扫描` | 本轮还没扫 |
| `不可作主口` | 该口不能作为主网口 |
| `已中断` | 快扫被中断 |
| `失败` | 扫描失败 |

颜色：黑色=扫到从站；灰色=空口/未测出/未扫描/不可作主口/已中断；橙色=主站占用；红色=失败或异常。

### 选主网口 / 冗余网卡

- `主网口(&P):` 选主网口。
- `冗余网卡(&R):` 可选；不需要就保持 `不使用`。冗余网卡不能和主网口相同。
- `刷新驱动` 只重新枚举网卡列表，不动系统网卡状态。
- `确认(&O)` 提交选择并关闭对话框；主窗口随后开始初始化。
- `取消(&C)` 只放弃这次网卡选择，不恢复旧主站。

注意：点 `切换` 会先关闭当前主站（等待窗 `正在停止主站` / `正在关闭当前主站连接，请稍候...`），再打开 `加载网卡`；取消后要重新 `切换` 选卡才能再建主站。

确认时的拦截提示：还在快扫 → `正在快扫网口，请稍候`；扫描中 → `正在扫描中，请等待扫描完成`；没选主网口 → `请选择主网口`；冗余和主口相同 → `冗余网卡不能与主网口相同`。

### 在对话框里先扫一遍

`扫描从站(&S)` 用当前主网口做一次扫描，把结果显示在对话框下方的从站列表里，列是：

`序号`、`从站名称`、`厂商ID`、`产品代码`、`版本号`、`配置地址`、`别名地址`

扫到 0 个时，状态行显示 `未发现从站`，并弹 `当前网口未发现从站。请选择已连接设备的网口后重新扫描。` 扫描失败会显示 `扫描失败(错误码 N): ...` 并弹错误框。

### 主窗口的 `扫描`

左栏 `扫描` 是“用当前已选网卡重建主站并重扫”，不是只刷新列表。它会复位配置就绪状态，状态机按钮在配置应用完成前保持灰色。

没选网卡就点 `扫描`，会提示 `请先选择主网卡适配器`。正常扫描/初始化失败会弹 `初始化失败`，正文以 `EtherCAT 主站初始化失败。` 开头，后面是真实原因和建议；`扫描从站失败，请查看日志面板了解详细原因` 只在未处理异常兜底时出现。

**怎么确认这一步成功了**：下拉里能看到网卡与 `从站数量`；对话框里 `扫描从站` 后从站列表出现行；点 `确认` 后主窗口出现初始化等待窗，随后从站树被填充。扫不到时先看 `从站数量` 是 `0`（实测空口）还是 `—`（没量到），不要混为一谈。

## 3. 加载配置

顶部 `导入` 菜单有三项：

| 菜单项 | 作用 |
|---|---|
| `ESI (从站描述)` | 导入单个 ESI XML，供从站匹配、对象字典、启动参数、PDO 使用 |
| `ENI (主站配置)` | 导入 ENI/DENI，关闭当前主站并按配置文件重建 |
| `DENI (主站配置)` | 导入 DENI（从站、PDO、DC、启动参数；已有主站时网口沿用当前网口） |

SERCOS 导入项已从菜单隐藏（功能未实现），界面上点不到。

### ESI

`导入` → `ESI (从站描述)` → 文件框标题 `导入 ESI 配置文件`，只收 `*.xml`。

- 成功后弹 `ESI 文件导入成功！`，带 `文件` 和 `位置`；若当前选中了 CoE 从站，CoE 页会刷新。
- ESI 解析/加入库失败时弹 `ESI 文件导入失败！`，带文件名、位置和原因；复制失败、权限不足或其它异常会分别弹 `无法复制文件`、`没有权限访问文件或目录` 或 `导入ESI文件失败`。失败时本次不会把文件算作已加载。
- 导入后看左侧从站树的 `ESI` 列：`✓` 精确匹配、`⚠` 版本不精确、`Y` 有 ESI 但未精确匹配、`✗` 无 ESI。该列在从站列表重建时更新。

ESI 不匹配会在状态切换前拦一次：弹 `ESI 匹配确认`，列出缺 ESI / Revision 不匹配的从站，说明继续有风险；`是` 继续，`否` 取消，总线不动。

### ENI / DENI

`导入` → `ENI (主站配置)` 或 `DENI (主站配置)`：

- 文件框分别收 `*.xml;*.eni;*.deni` 和 `*.deni;*.xml`。
- 导入会先关闭当前主站，再按配置重建；等待窗标题 `正在初始化`，描述 `正在导入配置并扫描从站，请稍候...`。
- 成功弹 `导入成功`，带文件名和结果消息，并刷新从站树。
- 失败弹 `导入失败`，带文件名和失败原因。
- DENI 带完整配置；标准 ENI 可能不带完整 PDO/SM 描述，仍需要 ESI 目录里的文件补齐。
- 已有主站时导入会沿用当前网口（覆盖文件里的网口信息），其余配置按文件重建。

加载完会自动选中 `Master`，先看到从站树、`信息`、`诊断`、`DC`、`CoE`、组页和 `主站配置`；点某个从站节点后，才按能力出现 `启动`、`FMMU/SM`、`PDO` 等从站页。PDO 实时值要等从站进 SafeOp/OP 才出现。

**怎么确认这一步成功了**：DENI/ENI 导入后弹 `导入成功` 且从站树有节点；ESI 导入后弹 `ESI 文件导入成功！`，树上的 `ESI` 列出现 `✓`/`⚠`/`Y`/`✗`。

## 4. 配置从站

在左侧从站树点一个从站节点。主站节点和从站节点显示的页不同：

| 页 | 什么时候出现 |
|---|---|
| `信息`、`诊断` | 主站建好后始终可见 |
| `DC` | 主站节点显示 DC 页（可改 `PDO交换周期`）；从站节点需支持 DC（显示主站 DC 周期读数 + DC 配置 + 同步窗口） |
| `启动` | 该从站支持 CoE，且主站处于 Init/PreOp 阶段 |
| `FMMU/SM` | 有 FMMU/SM 或支持 CoE，主站处于 Init/PreOp 阶段，且该从站不是 MDP |
| `CoE` | 主站节点显示；从站节点需支持 CoE |
| `SoE`、`EoE` | 对应能力，且 PreOp 及以上 |
| `FoE` | 支持 FoE，且 Boot/PreOp/SafeOp |
| `AoE` | 该从站支持 AoE |
| `VoE` | 支持 VoE；未判定时也放页，页内自陈结论 |
| `FSoE` | 能力已确认（ESI 声明/探测证实），或该从站有 FSoE 实例 |
| `PDO` | 该从站已到 SafeOp/OP，且输入或输出字节数大于 0 |
| `CiA 402`、`CiA 401` | 支持 CoE；到 PreOp 及以上后取不到 CiA 档案则隐藏（探测异常按未知放页） |
| `MDP` | 该从站支持 MDP |
| `主站配置`、组页 | 选中的是主站节点（`Master`）时 |

### PDO 映射怎么看、怎么改

常规入口是 `FMMU/SM` 页（主站处于 Init/PreOp 阶段、且该从站不是 MDP 时才出现；MDP 从站走 `MDP` 页）：

- 左表 `选择输入`，右表 `选择输出`。
- 勾选列 `选择`；其余列：`PDO索引`、`名称`、`SM`、`SM地址`、`SM长度`、`SM类型`、`PDO大小`；展开还能看到条目的 `名称`、`类型`、`长度`。
- 勾选或取消只**记录到启动计划**，不会立刻写设备。页面提示条会显示：`PDO 0x.... 已记录到启动计划，本次未向设备下发；将在下次状态转换时写入设备。`
- 下一次状态转换时写入设备；启动页生成 PDO 分配/映射条目时，`阶段` 是 Init→PreOp（IP）、`写入时机` 是转换完成后，以启动页表格显示为准。

要逐条改映射对象（例如 0x1C12/0x1C13、0x16xx/0x1Axx），去 `CoE` 页：

- CoE 表格按索引分组，列：`索引`、`名称`、`数据类型`、`访问权限`、`值`。
- 双击一行，打开 CoE 编辑对话框（标题 `编辑CoE参数 - 0x....`，`使用CoE 编辑SDO参数` 是设计期标题）：`参数信息`（`名称`、`索引`、`子索引`、`数据类型`、`访问权限`、`写入条件`）、`参数值`、`十六进制`，按钮 `确认`、`取消`、`刷新`。
- 完全只读对象双击时不会打开编辑器，而弹 `只读参数`：`对象 0x.... (...) 为只读。` + 当前值；进入编辑器后若判定只读，会按原因显示 `此参数为完全只读，无法修改` 或 `当前状态(...)下不可写，...状态可写`（无具体原因时才显示 `此参数只读，无法修改`）。
- CoE 读写在 PreOp 或 SafeOp/OP 进行；BOOT 下只允许 FoE，CoE 会被拒。PreOp 以下页内提示：`当前状态没有 CoE 邮箱，请先通过状态按钮进入 PreOp 后刷新`。

### 启动参数（Startup SDO）

`启动` 页是状态切换时要写的 SDO 计划：

- 列：`阶段`、`写入时机`、`索引`、`子索引`、`名称`、`数据`、`完整访问`。
- 按钮：`新建...`、`删除...`、`编辑`、`上移`、`下移`。
- `新建...` 打开 `从对象目录中选择条目`，`编辑` 打开 `编辑启动配置`；两者都要选对象并填 `参数信息`（`名称`、`索引`、`子索引`、`数据类型`、`访问权限`、`写入条件`、`完整访问(CA)`）、`参数值`、`写入时机`（`切换前`/`切换完成`）、`状态转换`（`O -> S`、`S -> P`、`S -> O`、`I -> P`、`P -> S`）。
- 右栏 `从站配置` 的 `开始自动配置` 会从 ESI/对象字典生成整套启动参数，弹 `已生成 N 项启动参数，确认替换完整启动计划？`；确认后替换当前计划。
- 计划有变化时，启动页的提示条可通过 `重新读取` 放弃未提交修改、重读设备上的完整计划（会先确认）。

选择 PDO 时如果计划里缺了多步序列的某一步，日志会记 `启动计划含不完整多步写入`；这种计划下发后设备可能停在半配置状态，先补齐再切状态。提示条只说“下次状态转换”，具体哪次看启动页的 `阶段` / `写入时机` 列（PDO 分配/映射默认是 Init→PreOp、转换完成后）。

### 从站组与 PDO 写入开关

右栏 `从站配置` 面板（选中从站时出现）：

- `写入PDO分配`、`写入PDO配置`：控制启动时是否写 PDO 分配/配置。
- `组:`：从站组号 0–7；0 是默认组，1–7 是显式分组。
- 主站节点下的组页可看 `组状态`、`组配置`（`组号`、`分频器`、`从站数`、`期望响应数`、`实际频率`），改完点 `应用组配置`。

**怎么确认这一步成功了**：勾选 PDO 后出现 `PDO 0x.... 已记录到启动计划...` 提示；`启动` 页能看到条目；`开始自动配置` 弹出生成数量确认框；`FMMU/SM`/`启动` 页在 PreOp 下可见、进 SafeOp/OP 后按规则收起。

## 5. DC 配置

DC 页随选中对象分两种。

### 主站节点（Master）

- 只有 `PDO交换周期`：填 ns，点 `保存`。只要不在 OP，且当前没有状态切换/异步操作，就可以改；下限 1000 ns（1 µs），非法值提示 `PDO交换周期值无效` 或 `PDO交换周期必须为 1000ns (1us) 以上`。

### 从站节点（支持 DC）

顶部 `主站DC周期` 是只读的总线周期读数（含 PDO 交换周期和人类可读值）。

DC 模式/SYNC0/SYNC1 控件只在 PreOp 可改；其它状态页内显示 `运行中只读 — DC 配置请在 PreOp 状态下设置`，同步窗口监视仍继续刷新。

1. 只读模式框：显示当前实际生效的模式，四选一：`自由运行 (FreeRun, 不同步)`、`SM 同步 (SM 事件触发)`、`DC 同步 (SYNC0)`、`DC 同步 (SYNC0 + SYNC1)`。这个框只显示，不能在这里切换模式。
2. 模式开关（互锁）：`FreeRun 自由运行`、`SM 同步`、`SYNC0 启用/禁用`、`SYNC1 启用/禁用`。
3. `SYNC0周期(×PDO)`：SYNC0 周期是 PDO 周期的倍数；`偏移(%周期)`：相位偏移，单位是周期百分比。填完点 `保存`。
4. `SYNC1周期(×SYNC0)`：SYNC1 周期是 SYNC0 的倍数，填完点 `保存`。
5. `同步窗口监视器 (0x092C)`：`当前差值`、`最大`、`最小`、`同步状态`、`失步次数`，按钮 `重置统计`。

偏移填 0 会弹确认框 `DC 偏移为 0 — 请确认`，说明 0 偏移会让从站报同步错误并掉出 OP；按钮是 `取消`、`使用推荐值 N%`、`仍要使用 0（不推荐）`。

参考从站：界面**不能指定**。主站按拓扑顺序和 DC 能力自动选参考钟（ESI 声明 DC-Sync0/SYNC01 的站优先，同档取站号最小的站；不看是否已武装），DC 页只在 `同步状态` 里显示 `参考钟`。SDK 当前也没有“用户指定参考钟”的配置入口。

**怎么确认这一步成功了**：主站节点能改 `PDO交换周期` 并保存；从站节点在 PreOp 下开关和两个 `保存` 可点；`同步状态` 给出 `已同步`/`未同步`/`参考钟`/`未参与 SYNC0 同步`/`无 DC 能力` 等明确结论，而不是空白或假的 0。

## 6. 启动主站 → 进 OP

按这个顺序：

1. `切换` → `加载网卡` → 选 `主网口`（可选 `冗余网卡`）→ `确认(&O)`。
2. 等待窗显示 `正在初始化` / `正在扫描从站并加载数据，请稍候...`；命中缓存时显示 `快速启动` / `使用缓存配置快速启动，请稍候...`。初始化成功时主站停在 **PreOp**（成功文案是 `配置完成，已处于 PreOp；如需运行请在状态机中切 OP`）。
3. 左侧从站树出现 `Master` 和从站行；状态栏开始显示频率、RTT、WKC、在线数等。
4. 顶部 `状态机` 下拉有 `INIT`、`PRE_OP`、`SAFE_OP`、`OP`、`BOOT` 五个瓦片。主站已建但配置还没应用完时，前四个瓦片是灰的，底部状态栏显示 `正在应用配置…`。
5. 点 `OP`（也可以逐级点 `PRE_OP`→`SAFE_OP`→`OP`）。等待窗标题 `状态切换`。
6. 如果 ESI 匹配有问题，会先弹 `ESI 匹配确认`：`是`=按当前 ESI 继续（有风险），`否`=取消，总线不动。
7. 失败时弹窗标题 `状态切换失败`，正文是真实原因；如果是启动参数问题，另弹 `从站配置错误`，正文以 `以下从站配置失败：` 开头列出从站。
8. `BOOT` 是单从站固件升级模式：必须先选中一个支持 FoE、且当前处于 Init 的从站。条件不满足时 `BOOT` 瓦片是灰的、不可点；如果状态在点击瞬间变化、二次校验失败，才弹 `BOOT 模式条件不满足`。切换失败弹 `从站 N (...) 进入 BOOT 失败.` 并给出 `实际 AL Status Code`。

常见失败提示：

| 情况 | 界面提示 |
|---|---|
| 没选主网口 | `请选择主网口` / `请先选择主网卡适配器` |
| 冗余口与主口相同 | `冗余网卡不能与主网口相同` |
| 初始化失败 | `初始化失败`：`EtherCAT 主站初始化失败。` + 原因 + 建议 |
| 扫描到 0 站 | 对话框状态行 `未发现从站`，弹窗标题 `提示`、正文 `当前网口未发现从站。请选择已连接设备的网口后重新扫描。`；初始化失败原因是 `未扫描到任何从站`，并提示确认供电/接线 |
| 配置未就绪 | 状态机瓦片灰色，底部 `正在应用配置…` |
| ESI 缺文件/版本不匹配 | `ESI 匹配确认` |
| 状态切换失败 | `状态切换失败` |
| 启动参数下发失败 | `从站配置错误` + `以下从站配置失败：` |
| BOOT 条件不满足 | `BOOT` 瓦片灰色不可点；只有二次校验失败才弹 `BOOT 模式条件不满足` |
| BOOT 切换失败 | `从站 N (...) 进入 BOOT 失败.` + `实际 AL Status Code` |

成功的表现：日志出现 `[SDK] 主站状态变化` 和 `[SDK] 主站已进入 OPERATIONAL 状态`；状态栏 `在线: N/N`；从站树状态列出现 `O`；`PDO` 页出现。

**怎么确认这一步成功了**：`在线` 计数等于从站总数；每站 `状态` 列是 `O` 或 `S`（不是 `-`/`!`/`~`/`Ox`）；`PDO` 页能打开并显示输入/输出值。

## 7. 实时监视

### 从站树状态列

左侧状态列只显示 1–2 个符号，完整语义在鼠标悬停提示里：

| 符号 | 含义 |
|---|---|
| `O` / `S` / `P` / `I` / `B` | 真实基态：OP / SafeOp / PreOp / Init / Boot |
| `Ox` 等 | 基态字母 + `x`：假 OP（无过程数据） |
| `-` | 真离线/掉电 |
| `?` | 不可达（探针盲区，不是离线） |
| `~` | 未知/未采样 |
| `.` | 快照占位（补读中） |
| `!` | AL 错误/故障位，全列唯一红色 |

### PDO 值

`PDO` 页要等该从站到 SafeOp/OP 且输入/输出字节数大于 0 才出现。页分左右两栏：左栏输入（TxPDO），右栏输出（RxPDO）。控件按数据类型自动生成：位/布尔用开关，数字/字节/浮点/字符串用对应输入框。

- 输入值只读，随过程数据刷新。
- 输出值可编辑，但只有从站处于 OP 时才真正写入；OP 之前控件只读。空值、无法解析或被拒绝的写入不会把 0 写进过程映像，日志面板会记拒写原因。
- 写成功后值保持并每周期下发；要在每周期做计算（斜坡、插补、状态机），不要在这里手填，去写程序。

### 信息页

选中从站时，`信息` 页按 `Category` 分组，列是 `Parameter`、`Value`、`Unit`、`Description`（运行时表头为英文）。常用组：

- `状态信息` → `AL状态码`
- `通信质量` → `工作计数器(WKC)`
- `网络配置` → `链路状态`
- `分布式时钟(DC)` → DC 支持、激活状态、周期、偏移、接收时间
- `PDO映射` → 输入/输出字节数、位数、偏移
- `协议支持`、`邮箱配置`、`拓扑`、`标识信息`、`电源信息`、`时序信息`

### 诊断页

- `主站诊断`：`健康值`、`主链路状态`、`副链路状态`、`冗余状态`、`最差链路质量`、`最差从站`、`帧错误`、`丢失帧`、`校验和错误`、`超时帧`、`数据校验错误`、`连续校验失败`、主/副端口错误、`总错误`、`错误率(‰)`、主/副端口 Tx/Rx。
- `实时性能`：`发送频率`、`峰值抖动`、`往返延迟`、`邮箱收发延迟`、`平均抖动`、`干净最大`、`SMI 次数`、`SMI 峰值`、`通讯负载`。
- `DC 同步`：`定时模式`、`最大同步差`、`拓扑模式`。
- 拓扑图占满下半区；鼠标悬停到从站可看在线/离线、AL 码、WKC 探针。
- 工具条：`自动重扫`（默认开）与 `热插拔重建`。热插拔重建适合运行中插/拔站；OP 中执行会先提示 PDO 会短暂中断。

### 状态栏

底部最左是工作状态（初始 `未连接`，忙碌时显示当前动作），其后是主站状态（如 `OP`、`离线/掉电`、`未知`），再后是 `频率`、`抖动`、`RTT`、`WKC`、`丢包`、`在线`、`SMI`。`在线` 显示 `N/N`，有离线站时带 `离线从站:` 列表；`WKC` 是实际/期望工作计数器。

**怎么确认这一步成功了**：`频率` 有非零值、`WKC` 不是 `--`、`在线` 计数正确；`信息` 页 `AL状态码` 与树状态一致；`诊断` 页数值持续变化且拓扑图节点与实物拓扑一致。

## 8. 日志与导出

### 日志

主界面底部是 `Logs` 面板，数据列是图标、类别、消息、时间；表头行隐藏，界面上看不到列名。面板顶部有类别筛选按钮：`Debug`、`PDO`、`Mailbox`、`Message`、`Warning`、`Error`、`Local`，按钮是勾选式，取消哪类就不显示哪类。

用户点击、状态变化、失败原因都会进这个面板。排查时先看 `Error`/`Warning`。

### 导出

顶部 `导出` 下拉：

- `模板程序`：打开 `导出程序` 窗口。
- `Debug信息`：生成一份调试信息文本并直接用记事本打开（临时文件，不弹保存框）。

`导出程序` 窗口左侧分组：

| 分组 | 项目 |
|---|---|
| `导出` | `DENI 配置文件`、`详细信息` |
| `对应程序` | `C#`、`Python`、`Java`、`C`、`C++`、`Rust` |
| `诊断信息` | `调试信息`、`导出日志` |
| `设置` | `需要注释`、`FoE 文件传输`、`EoE 以太网配置`、`SoE 伺服参数`、`AoE ADS 通信`、`MasterIO 静态映射` |

用法：

- 点语言项：右侧生成该语言的调用案例；工具栏 `Copy` 复制到剪贴板，`Export` 保存。
- 保存语言项会走 `选择导出目录 (将创建 EtherCATRestore 子文件夹)`，生成完整项目目录（源码 + 配置 + SDK + 运行脚本）；目录已存在会问是否覆盖。
- `DENI 配置文件`：生成预加载配置，再用 `导出文件` 保存框存成 `*.deni` 或 `*.xml`。
- `详细信息`：生成 Excel 报告；用 `Export` 选 `*.xlsx` 保存。
- `调试信息` / `导出日志`：在窗口里显示文本内容，用 `Export` 保存。

未初始化主站时，`模板程序`/导出程序会被拦下并提示先初始化主站；`Debug信息` 仍会生成文本（里面写 `主站未初始化`）并用记事本打开。

**怎么确认这一步成功了**：`Logs` 面板有本次操作记录；导出窗口里能看到生成的代码/配置文本；保存后弹出 `已保存到`（Excel）、`代码已保存到`（文本/DENI）或 `项目已导出到`（完整项目），文件确实存在。

## 9. 界面里做不到的事

认清楚边界，别在界面里找不存在的入口：

| 想做的事 | 界面为什么不行 | 怎么做 |
|---|---|---|
| 在周期回调里写业务逻辑（斜坡、插补、状态机、联锁） | 界面只能手工改 PDO 输出值，没有代码或脚本入口 | 写主站程序，用 `darra-ethercat` 技能 |
| 伺服使能、模式切换、运动控制 | `CiA 402` 页只做状态监视；页内明确写“驱动器的使能、模式切换和运动控制请通过用户程序 (SDK) 或厂商专用工具完成” | 写 SDK 程序，或用厂商工具 |
| 指定参考从站 | 参考钟由主站自动选；界面只显示 `参考钟`，没有选择入口 | 当前只能接受自动选择 |
| SERCOS 导入 | 菜单里没有这一项（代码分支保留但隐藏） | 暂无 |
| 保存“工程文件” | 没有工程保存按钮 | 用 `导出` → `DENI 配置文件` 留存配置 |
| 编辑/新建 ESI | 只能导入 XML | 用外部编辑器改 ESI 后重新导入 |
| 新建 PDO 映射条目 | `FMMU/SM` 只能勾选已有 PDO；没有映射编辑器 | 在 `CoE` 页逐条改映射对象（高级、易错），或改 ESI 后重导入 |
| 监视 PLC 变量或写 PLC 逻辑 | 这个工具只做主站配置与监视 | 用 PLC IDE/程序 |

需要写代码时，转到 `darra-ethercat` 技能；API 名称、初始化顺序、状态机、PDO、SDO、CiA 402、DC 都以 https://ethercat.darra.xyz/ai-prompts.txt 为准，不要凭这份界面文档猜接口。
